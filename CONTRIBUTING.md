# Bijdragen aan Mondig

Mondig is open source onder de [EUPL-1.2](LICENSE) en wordt gemaakt door Aigenwijs.

## Meldingen en wensen: graag

Zie je een fout, of mis je iets? Maak een issue aan met het sjabloon voor een fout of een wens.
Zet er nooit opnames, transcripten of andere persoonlijke gegevens in.

Een beveiligingsprobleem meld je niet in een issue, maar zoals beschreven in
[SECURITY.md](SECURITY.md).

## Code: voorlopig niet van buiten

We nemen op dit moment geen pull requests van buiten Aigenwijs aan, omdat de rechten op alle code
bij Aigenwijs moeten blijven liggen. Een pull request van buiten sluiten we daarom met een
bedankje, ook als hij goed is. Wil je iets bijdragen, open dan eerst een issue; dan zoeken we
samen een weg.

Je mag de code natuurlijk wel gebruiken, aanpassen en zelf verspreiden onder de voorwaarden van
de EUPL-1.2.

# Contributing to Mondig

Mondig is open source under the [EUPL-1.2](LICENSE), made by Aigenwijs.

Bug reports and feature requests are welcome as issues. Never include recordings, transcripts
or other personal data. Report security problems as described in [SECURITY.md](SECURITY.md).

For now we do not accept pull requests from outside Aigenwijs, because Aigenwijs needs to hold
the rights to all code. You are free to use, modify and distribute the code under the terms of the EUPL-1.2.
